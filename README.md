# UniNexora — Professional GitHub Pages Edition

## Included
- Responsive single-page university admission hub
- Professional UniNexora logo
- University search + filters
- Official university links
- Entry-test planning cards
- Percentage, weighted-merit and test-score calculators
- Local profile using browser localStorage
- Admission tracker with status updates
- Mobile navigation
- Dark/light theme
- GitHub Pages compatible — no backend required

## Deploy
1. Create/open a GitHub repository.
2. Upload all four files: `index.html`, `style.css`, `script.js`, `logo.png`.
3. Commit the files.
4. GitHub → Settings → Pages → Deploy from branch → select `main` and `/ (root)`.
5. Open the Pages URL after deployment.

## Important
The profile and tracker are stored only in the visitor's browser. This is not secure server-side authentication. Do not use it for sensitive passwords or private information.

University admission rules and dates can change. The site intentionally directs users to official university websites for final verification.
